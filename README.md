# Ворчливая погода (Grump Weather Reborn)

Прогноз погоды для Android, который материт любую погоду. Тепло — «ебучая жара», холодно — «холодрыга ебаная», влажно — «болото ебучее», и ещё куча вариантов.

## Что умеет

- Текущая погода с ворчливым заголовком и «советом». Тапни по заголовку, и он обосрёт погоду другими словами.
- Больше 20 «настроений» погоды: гроза, метель, гололёд, ливень, морось, туман, ураган, дубак, слякоть, хамсин, пекло, баня, жара, болото, хмарь и т. д.
- Мелкие поводы поныть сверху: ветер в ебало, порывы, сырость, сухость, «по ощущениям ещё хуже».
- Почасовой прогноз на сутки и прогноз на 7 дней, у каждого часа и дня своя ворчливая подпись.
- Город ищется поиском или определяется по геолокации. Последний город запоминается.
- Фон меняется в зависимости от погоды и темнеет ночью.

Погода берётся из [Open-Meteo](https://open-meteo.com): без ключей и регистрации.

## Где взять APK

Каждый пуш в `main` собирается в GitHub Actions, а APK выкладывается в **Releases**.

Чтобы новые версии ставились поверх старых, все сборки подписываются одним ключом. Ключ хранится в секретах репозитория (Settings → Secrets and variables → Actions):

- `KEYSTORE_BASE64`: keystore в base64, alias `grump`
- `KEYSTORE_PASSWORD`: пароль от него

Без секретов APK подписывается одноразовым debug-ключом. Такой APK ставится, но поверх предыдущей версии не обновится.

## Где лежат фразы

Все фразы лежат в `app/src/main/java/com/ivan/grumpweather/grumpy/Grumpy.kt`. Там же правила, по которым погода превращается в «настроение». Чтобы добавить вариант, допиши строку в нужный список.
